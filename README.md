# CCAR-F · estudio local

App para preparar **Claude Certified Architect – Foundations**. Las lecciones, tarjetas y preguntas son material original alineado a las tareas (task statements) de la Exam Guide oficial, versión 1.0 vigente desde julio de 2026. No sustituye el PDF oficial ni el learning path del programa de partners.

## Arrancar

Hace falta Node 18 o superior. No hay dependencias que instalar.

```bash
node server.js
```

Abre http://localhost:4173

El progreso (lecciones, tarjetas, simulacros y la lista de preparación) queda en este navegador.

## Qué hay dentro

- 30 lecciones en los 5 dominios, con el peso del examen
- Tarjetas con repaso (otra vez / bien / fácil)
- Práctica por dominio, en modo estudio o examen
- Simulacro de 60 preguntas y 120 minutos, mezclado como los pesos oficiales
- Los 6 escenarios que la guía publica, como decisiones y no como respuestas memorizadas
- Distinciones, glosario, temas que no entran, y la logística de Pearson VUE

Las preguntas de práctica están en inglés. Las explicaciones están en español.

Si el PDF y el producto de hoy no dicen lo mismo, en el examen se responde como el PDF.
